# Building Curtain Firmware

## Prerequisites

- Docker
- VS Code with the [Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers) (for IDE workflow)

## Build the Docker image

```bash
./build-docker.sh
```

This builds the `curtain-firmware` image based on Ubuntu 24.04 with:
- pico-sdk 2.2.0 at `/pico-sdk`
- ARM GCC 13 toolchain (`gcc-arm-none-eabi`)
- clangd 18
- OpenOCD (Raspberry Pi fork, rp2040 branch)

This step takes several minutes the first time due to cloning the SDK submodules and building OpenOCD.

## Build the firmware

Start the container with the `firmware/` directory mounted:

```bash
./run-docker.sh
```

Inside the container, configure and build:

```bash
mkdir -p build && cd build
cmake ..
make -j$(nproc)
```

The build outputs land in `firmware/build/`:
- `blink.uf2` — drag-and-drop onto Pico W in BOOTSEL mode
- `blink.elf` — used for debugging via OpenOCD

## Flash via OpenOCD (picoprobe)

From the project root on the host (with OpenOCD and a picoprobe connected):

```bash
./flash.sh
```

Or from inside the container with `--privileged` and the probe device passed through.

## VS Code / Dev Container (IDE workflow)

1. Build the Docker image first (`./build-docker.sh`).
2. Open the project root in VS Code.
3. When prompted, click **Reopen in Container** (or run `Dev Containers: Reopen in Container` from the command palette).
4. VS Code attaches to the container with the `firmware/` folder as the workspace.
5. Run the cmake configure + build steps above (or use the CMake Tools extension UI).
6. clangd reads `firmware/build/compile_commands.json` for accurate IntelliSense — build at least once before expecting full IDE support.

### clangd notes

- The `compile_commands.json` is generated by CMake (`CMAKE_EXPORT_COMPILE_COMMANDS ON`) into `firmware/build/`.
- A symlink `firmware/compile_commands.json -> build/compile_commands.json` is present so clangd can also find it from the source root.
- The MS C++ IntelliSense engine is disabled in `.vscode/settings.json`; clangd handles everything.
